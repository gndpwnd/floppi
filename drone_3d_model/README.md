# drone_3d_model

3D modeling and frame design for drone platforms — chassis, sensor mounts, and component layouts for various configurations (quadcopter, hexacopter, custom VTOL).

## Overview

This sub-project handles all physical drone design: frame geometry, motor mounting, sensor placement, and structural considerations. Designs target 3D printing and off-the-shelf components.
