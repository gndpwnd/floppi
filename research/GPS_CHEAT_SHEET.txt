GPS OUTPUTS & ACCURACY
────────────────────────────────────────────────────────────────────────────────

  From GPS Module (NEO-M9N):
  • Latitude/Longitude    → ±2-5m (horizontal)
  • Altitude (HAE)        → ±5-10m (ellipsoidal height)
  • HDOP (Horizontal DOP) → Indicates geometry quality
  • VDOP (Vertical DOP)   → Usually 1.5-2x HDOP
  • Satellites            → Need 8+ for good accuracy
  • Fix Quality           → 1=GPS, 4=RTK fixed

  HDOP Values:
  < 1.0   → Ideal (rare)
  1-2     → Excellent   (≈±6m error)
  2-5     → Good        (≈±15m error)
  5-10    → Moderate    (≈±30m error)
  > 10    → Poor        (unreliable)

ALTITUDE REFERENCE SYSTEMS
────────────────────────────────────────────────────────────────────────────────

  HAE (Height Above Ellipsoid)        MSL (Mean Sea Level)       AGL (Above Ground)
  ───────────────────────────         ─────────────────          ──────────────────
  GPS direct output                   Navigation charts          Obstacle avoidance
  500.0 m (mathematical)              500.0 - 46.9 = 453.1 m     453.1 - 100 = 353.1 m

  Formula: MSL = HAE - N              Formula: AGL = MSL - terrain

  Where N = geoid undulation (±50-100m globally)
  Use NOAA Geoid Height Calculator for your location

MAGNETIC HEADING CORRECTION
────────────────────────────────────────────────────────────────────────────────

  Magnetic Heading (from magnetometer)
       ↓ (add declination)
  True Heading (relative to geographic north)

  Formula: H_true = H_magnetic + declination

  Example: Magnetometer reads 45°, declination is -12° (West)
           True heading = 45° + (-12°) = 33°

  Get declination from: https://www.ncei.noaa.gov/geomag-web/

  Typical Values (2024):
  San Francisco:  +11°53' E (East)
  New York:       -12°15' W (West)
  London:          -0°43' W (West, changing to East)
  Tokyo:           -8°00' W (West)
  Sydney:         +12°24' E (East)

ECEF ↔ WGS84 CONVERSIONS
────────────────────────────────────────────────────────────────────────────────

  WGS84 Constants:
  a = 6,378,137 m (semi-major axis)
  e² = 0.00669437999014 (eccentricity squared)

  Geodetic → ECEF:
  N(φ) = a / √(1 - e² sin²(φ))
  x = (N + h) cos(φ) cos(λ)
  y = (N + h) cos(φ) sin(λ)
  z = (N(1 - e²) + h) sin(φ)

  ECEF → Geodetic: Use iterative method (see full docs)

NED FRAME DEFINITION
────────────────────────────────────────────────────────────────────────────────

           ↑ North (X)
           |
           o─────→ East (Y)
          /
         ↙ Down (Z)

  Standard in aviation and UAV control
  Z positive = downward (toward gravity)

  Rotation matrix for ECEF → NED:
  R = [[-sin(φ)cos(λ)  -sin(λ)  -cos(φ)cos(λ)]
       [-sin(φ)sin(λ)   cos(λ)  -cos(φ)sin(λ)]
       [ cos(φ)         0        -sin(φ)    ]]

  Where φ = latitude, λ = longitude

BODY FRAME (AIRCRAFT AXES)
────────────────────────────────────────────────────────────────────────────────

  Euler Angles (ZYX convention):
  φ (Roll)     → Rotation about forward (X) axis
  θ (Pitch)    → Rotation about right (Y) axis
  ψ (Yaw)      → Rotation about down (Z) axis

  Positive:
  Roll +    = Right wing down
  Pitch +   = Nose up
  Yaw +     = Clockwise (viewed from above)

COMMON MISTAKES (DON'T DO THESE)
────────────────────────────────────────────────────────────────────────────────

  ✗ Using HAE for obstacle avoidance
    Right: Convert to MSL/AGL first (use geoid model)

  ✗ Mixing NED and ENU in same calculation
    Right: Pick one frame and stick with it (NED for drones)

  ✗ Ignoring magnetic declination
    Right: Always apply declination = magnetometer ↔ true north

  ✗ Assuming GPS is always accurate
    Right: Check HDOP < 2.5 and satellites ≥ 8 before trusting

  ✗ Using GPS latitude directly as meters
    Right: Convert through ECEF/NED for proper distances

DEBUGGING QUICK LINKS
────────────────────────────────────────────────────────────────────────────────

  GPS position wrong?
  → Check: fix_quality ≥ 1, satellites ≥ 8, HDOP < 5.0
  → Issue: Multipath (near buildings/trees)

  Altitude off by 100m?
  → Check: Are you using correct geoid model? (NOAA for location)
  → Formula: MSL = HAE - N (where N varies by location)

  Heading doesn't match?
  → Check: Magnetometer calibrated? Declination applied?
  → Formula: true = magnetic + declination

  Position drifts over time?
  → Normal: GPS has natural jitter (HDOP variation)
  → Fix: Add Kalman filter to fuse with IMU

  Math doesn't work?
  → Check: Input in degrees? Output in radians?
  → Verify: Round-trip test (Lat→ECEF→Lat should match)

STANDARDS REFERENCE
────────────────────────────────────────────────────────────────────────────────

  Altitude Terms (FAA/ICAO):
  • HAE:  Height Above WGS84 Ellipsoid (GPS output)
  • MSL:  Mean Sea Level (navigation/aviation)
  • AGL:  Above Ground Level (obstacle avoidance)
  • QNH:  Pressure altitude setting (aviation only)
  • FL:   Flight Level (cruise altitude, aviation)

  Frame Standards:
  • NED:  Aviation/UAV standard (X=north, Y=east, Z=down)
  • ENU:  Robotics/mapping (X=east, Y=north, Z=up)
  • ECEF: Satellite/geodetic standard (Cartesian Earth-center)

MATH REFERENCE CARD
────────────────────────────────────────────────────────────────────────────────

  Useful Constants:
  π ≈ 3.14159265359
  Earth radius: 6,371,000 m (mean)
  1 degree latitude ≈ 111,000 m
  1 degree longitude ≈ 111,000 × cos(latitude) m

  Angle Conversions:
  radians = degrees × π/180
  degrees = radians × 180/π

  Distance Approximation (local, < 1 km):
  Δlat [m] = Δφ [degrees] × 111,000
  Δlon [m] = Δλ [degrees] × 111,000 × cos(φ)

  Vector Magnitude:
  |v| = √(x² + y² + z²)

  Rotation Matrix (NED to Body):
  Apply three sequential Euler angle rotations (ZYX order)
