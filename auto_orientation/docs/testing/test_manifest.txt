SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues:

1. "Tests ran: 0"
   → Check file paths, run from project root

2. "BNO085_InitializationBegins - FAILED"
   → Sensor not connected, check Serial1, baud rate

3. "QuaternionMagnitudeValid - FAILED"
   → Quaternion not normalized, check library version

4. "NEO_M9N - FAILED"
   → GPS needs outdoor location for fix, wait 30+ seconds

See docs/integration_test_guide.md for detailed troubleshooting.
